Latency at the optimal point (minimum latency at maximum recall) for each algorithm. The fastest system is shown as 1x, others are relative (higher = slower).

Relative Search Throughput

Throughput at the optimal point (maximum throughput at maximum recall) for each algorithm. The system with the lowest throughput is shown as 1x, others are relative to that (higher = more queries per second).
